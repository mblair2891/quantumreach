# Commercial cost model

Planning defaults use $15.25/domain/year, $1/mailbox/month, and $0.10/1,000 outbound messages plus editable hosting, database, authentication, storage, monitoring/jobs, operations/support, payment-processing, replacement, and provider-failure reserves. Default practical monthly COGS ranges are Launch $32–$57, Growth $81–$143, and Scale $168–$298. These are **planning estimates**, not accounting claims. Actual provider costs, credits, refunds, and adjustments are separately recorded and operator-only.

The operator economics page separates projected plan economics from actual provider-cost entries. Detail covers domain, mailbox, transport, hosting, database, authentication, storage, support, payment-processing, and replacement reserves; actual costs remain operator-only.
