# Managed domain provisioning

Flow: search domain, quote Quantum Reach resale price, select ownership mode, review registrant profile, accept registrant attestation, create a purchase request with immutable snapshot, pass billing/authorization, and execute registrar registration only when provider and production purchasing are enabled.

Customer UI should show resale/renewal pricing and ownership explanations. Operator UI may show wholesale cost and readiness indicators. Customer-owned renewals are billed through Quantum Reach; leased Quantum Reach-managed domains remain Quantum Reach property.
